# Projet Wordle
## Contexte
Il s'agit d'un projet personnel permettant d'apprendre les bases d'Android Studio. Il s'agit d'un projet reprenant le jeu du wordle, dans lequel le joueur dispose d'un certain nombre de tentatives pour trouver le bon mot.

## Objectifs
Dans ce projet, j'ai pu explorer plusieurs concepts lié à la conception d'applications Android en Java :
- Utilisation de sharedPreferences, permettant de stocker des données en mémoire au sein de l'application
- La génération de layouts dynamiquement
- L'utilisation de boîtes de dialogue
- La définitions de styles dans des fichiers XML
- La mise en place de menu de navigation
- La création de fragments au sein d'une activité

Ce projet a donc un but purement éducatif et personnel. Celui-ci permet de maîtriser les bases du développement Android.
